# コトマス / コトマスN2

- `../nihongo_crossword.html`: 既存の初級・中級・上級22盤面。既存の盤面IDと保存キーを保持。
- `../nihongo_crossword_n2.html`: 添付Excel全6課・1,150語をカバーする131盤面。
- `game.js`: 共通の入力、答え合わせ、ヒント、語彙帳、ご褒美の処理。
- `classic-data.js` / `n2-data.js`: 語彙と固定盤面。再読み込みしても同じ問題を再開できる。
- `logo.png`: 既存ページに埋め込まれていたロゴを変更せず共通化。

## ヒント

`hintExample` の `{{blank}}` を「頭文字＋○」に置き換える。○は盤面の文字数から1を引いた数で、赤色は頭文字のみ。小書き仮名は既存のルールどおり大きな文字に正規化する。N2の例文は原文を優先し、活用形が読みと合わない場合は `scripts/n2-hint-examples.json` に収録した学習用の文を使う。元の例文は復習用に保持する。

## ご褒美と保存

両ゲームで `kotomas-rewards-v1` を共有する。1回クリアで1個、1/3/5/10/20/30個でコレクションを開放。40個以降は10個ごとに花束。途中保存に `roundId` を持ち、同じ回の再読み込みや重複した答え合わせでは加算しない。最初からやり直して再クリアすると新しい回として加算する。ヒント使用による減点なし。

既存の語彙帳は両ゲームで共有し、N2の途中保存・記録は専用キーに分離する。クリア記録の削除ではご褒美を消さない。保存できない環境でも遊べるが、ご褒美の保存失敗を明示する。

## 開発・検証

ルートで `npm install` → `npm test`。`npm run build:n2` で添付Excelから抽出した `scripts/n2-source.json` とヒント文からN2データを再生成する。乱数シードは固定。全語彙が最低1盤面に含まれることを検証する。

テスト対象は153盤面の交差・連結・範囲・意図しない文字列の不存在、1,251語のヒント、全ヒント画面、解答、保存と復元、再挑戦と再読み込み、ご褒美の共有、語彙帳、記録削除、保存できない環境。実ブラウザでの描画確認は別途必要。

GitHub PagesにはHTMLと `kotomas/` のファイルを一緒に反映する。ビルド工程や外部APIは不要。
